Homepage Amazon Module

Three layout options for introducing the Amazon/Marketplace service on the Phase 3 Ecom homepage. Pick one to implement. Live previews rendered below.

Decision guide

When to use each option

Option A

Short module, integrated

Use when the Amazon service is one of many services listed on the homepage. Sits inside the existing services section without disrupting the page flow.

Option B — Recommended for launch

Standalone callout, promotional

Use when you want to launch the Amazon service with a promotional push — treat it as a new offer announcement. More visual real estate, leads with price and guarantee.

Option C

Minimal tile, services grid

Use when real estate is limited and the homepage is a high-level service index only. One tile in the existing services grid.

Implementation

Notes for dev handoff

Logo strip

The platform logo strip (already live on phase3ecom.com) already includes Amazon. Consider annotating it with "Now available as a managed service" or a tooltip to direct attention without adding a full new section.

Link target

All CTAs link to /amazon (the overview page). Once the full page set is live in Shopify, this path should resolve to the Amazon overview page built from page-amazon-overview.md.

Option A + logo strip

A viable hybrid: use Option A (short module) and annotate the existing logo strip with "Marketplace management now available" or a badge on the Amazon logo. Gets attention without a full standalone block.
